# Design System

## Style Principles
- Mobile-first
- Clean financial services app style
- Simple, accessible, low-clutter UI
- Use neutral colours
- Clear hierarchy
- Large touch targets
- Rounded cards and toggles

## Components
Use:
- Bottom navigation
- “More” menu
- Settings list rows
- Toggle switches
- Page header
- Back navigation
- Informational helper text

## Prototype Constraints
- This is a current-state prototype, not a future-state redesign
- Do not introduce new notification categories or features
- Keep the journey intentionally limited
- Prioritise behavioural accuracy over visual polish
